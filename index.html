เมื่อเชื่อมต่อแล้ว ข้อมูลจะซิงค์อัตโนมัติระหว่างมือถือและคอมพิวเตอร์

💡 ระบบจะ Pull อัตโนมัติทุก 30 วินาที และ Push ทุกครั้งที่บันทึกข้อมูล
วิธีตั้งค่า Google Apps Script (ทำครั้งเดียว):
1. เปิด Google Sheets → Extensions → Apps Script
2. วางโค้ดจากไฟล์ google_apps_script.gs ที่ได้รับ → กด Save
3. กด Deploy → New deployment → Web app
4. ตั้ง Execute as: Me / Who has access: Anyone
5. กด Deploy → Copy URL มาวางในช่องด้านบน → กด บันทึก URL
